# NOVA DEVLOG (public chronicle)

A streamlined history of how the homestead field kit grew.  
For metal-loop detail, checksums, and steward opinions, see **`DEVLOG.txt`**.

---

## Founding (late Aug – mid Sep 2026)

Intent: a **sovereign homestead agent** on everyday compute — Python spine, local Ollama, WHI palace, dual-use with human-in-the-loop.

Early field kits chased website-parity fantasies. Real metal on an everyday Windows machine forced honesty: daemon + jobs, matrix `/web`, PDF ingest, camera stills, Pocket TTS, ANSI TUI, forge catalog. The spine is real when jobs print in the daemon window. Theater does not ship.

## Leash and brain (v1.8)

Landed the leash layer and brain seam: breaklog, staff masks, OpenClaw / Qwen status jobs, cam-see into mail, GUI deck tiles for pets and breaks. Secrets stay under `data/secrets/` (stub only in public tree). Overlay discipline — live `NOVA.db` never rides in a zip.

## Mind-palace and WHI

Documents ingest days, AiTutor course stamps (`0x-DOC`), crawl + RAG worthiness gate, chamber (mixture of seats) with promote-to-RAG. Hunt and WHI indexes became the trust story: provenance before eloquence.

## Hearthbeat tentacles

UDP hearthbeat (beacon / jobs) so a hub NOVA can see slave nodes. First tentacle: Linux box profiled as a CPU digest / scout worker (lid-closed, always-on, thermal-paced). Acquisition profiles stayed operator-local (not shipped) — no passwords in the public tree.

## Pets, avatar, paint lanes

Pets playbook: steward as trainer; Aurelius (OpenClaw) executes with **PROOF**; Komodo drafts on a leash; Pocket TTS speaks (voice **anna**). Avatar / viseme / lipsync researched and staged. Paint debated between ComfyUI sidecar and Diffusers; GUI art mint scripts were kept operator-local (not shipped).

## GUI chrome + music (2026-09-26)

Four theme backgrounds minted (dark homestead, lunar command, frostshield glass, warm forge) plus procedural music beds; the mint scripts and WAVs stay off git. Diffusers used when ComfyUI hit Windows Application Control friction. Public GitHub publish prepared with proprietary LICENSE and scrubbed tree.

## Fieldkit 2.0 (2026-09-27)

First formal refactor: proven experiments folded into one tree, mail standardized on TCP (`docs/MAIL_PROTOCOL_TCP.md`), smoke suites 8/8.

## Fieldkit 2.1 (2026-10-14, tag `v2.1`)

One chat path with SELF/NOW self-knowledge, read-only GUI, scheduler v2 (job table, GPU classes, backoff, command inbox, task-stimulus), fail-closed gates with an empty-by-default net allowlist, HIL self-improve loop with PROOF, dry-run governor and disk retention, portable paths. Test suite: 59 tests (on Linux without PySide6: 46 pass, 13 skip). See `docs/GATES.md` and `docs/SCHEDULER.md`.
