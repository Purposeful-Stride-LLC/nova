PAGE 12  CRAWL AND WEB INGEST
--------------------------------------------------------------------------------
Crawl explores (same host). Web gate judges quality.

>> /crawl https://textual.textualize.io/guide/
Expect: pages + chunk_ids. Daemon equivalent: /job add 0 crawl:https://...

Crawl can enqueue URLs into the board; daemon ingest / tick drains them:
  board.enqueue_url -> job ingest / board.drain_one -> web.fetch
  Hit: 0x-WEB   Miss: Tx-REJECT (thin/JS/manipulated-looking pages later)

>> /web https://docs.python.org/3/library/curses.html
Expect: matrix score; ingest or reject-thin.


PAGE 13  RAG WORTHINESS GATE
--------------------------------------------------------------------------------
Palace knowledge is only as good as precise facts. RAG does NOT dump everything.

>> /rag textual CSS layout widgets
Expect: kept snippets with scores; small model INCLUDE/EXCLUDE; Ax-RAG stamp.

Flow: live chunks -> word/subject weight search -> tiny model gate -> prompt context.
Source facts stay written; only the conversation context is filtered.
Deeper base: Textual + Qt. Later: arXiv white papers via crawl+ingest.


PAGE 14  CHAMBER (MIXTURE OF EXPERTS)
--------------------------------------------------------------------------------
Design seats: claw + code + brief (qwen3:8b). Drop qwen2:0.5b from design
(optional keep only as RAG INCLUDE/EXCLUDE gate). Opinions land as Tx-TEMP
facts chamber/<case>/<seat> plus Ax-CHAMBER motion stamps.

IMPORTANT: /rag only reads chunks.status=live. Chamber temps are NOT RAG-visible
until promote_to_rag(case) copies them into live chunks.

>> /chamber list CASE_ID
>> /chamber clear CASE_ID
