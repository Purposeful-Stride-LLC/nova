NOVA field kit 2.1 - start card

Two processes (plus Pocket TTS if you want a voice).

  python -m nova          daemon: scheduler, DB writes, approved commands
  python -m nova.tui      metal face (edits the jobs table; /cmd approves proposals)
  python -m nova.gui      read-only operator console (START_GUI.bat)
  python -m pocket_tts serve --port 8000     voice (optional)

  /sched                 job table: priority, GPU class, next run, fails
  /job on ID|name        /job off ID|name
  /cmd list              proposals from chat, GUI and task-stimulus
  /cmd approve ID        the daemon runs it on its next tick
  /web URL               only hosts in data\config\gates.json net_allowlist

Chat proposes, the operator approves, the daemon does. Nothing auto-applies.
A STAGED kit (STAGED marker file) will not boot a daemon against live data.
