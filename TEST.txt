NOVA 2.1 test card
==================
Run from the install folder (the folder that contains nova/).
Never point tests at the live data/NOVA.db.

Automated suite:
  python -m pip install -r requirements.txt pytest
  python -m pytest -q tests
  Expect: 59 tests. Tests that need Windows, PySide6/Qt (offscreen:
  QT_QPA_PLATFORM=offscreen), Ollama, a staged kit, or a scratch DB copy
  (NOVA_SCRATCH_DB = path to a COPY of the DB) skip automatically.
  Example: Linux without PySide6 -> 46 passed, 13 skipped.

Manual smoke (two windows):
Window A:  python -m nova
  Expect: daemon line and the job table.

Window B:  python -m nova.tui
  /sched                 job table: priority, GPU class, next run, fails
  /cmd list              pending proposals (chat / gui / task-stimulus)
  /cmd approve ID        daemon runs it on its next tick
  /job off ID|name       /job on ID|name
  /web https://example.com
                         refused unless the host is in
                         data/config/gates.json "net_allowlist" (empty = refuse)
  /hunt example          palace rows, read-only, no LLM

Chat check: ask "Turn off the camera job." Expect a proposal, not an action.

GUI (optional):  python -m nova.gui
  Expect: read-only console; WHAT NOVA KNOWS and PROPOSALS panels;
  actions file proposals into the command inbox.

Disk / governor reports (dry-run only):
  python -m nova.disk report
  python -m nova.governor report
