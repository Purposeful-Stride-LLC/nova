TOOL NAME: nova.tts_tool.speak()
ALIAS: pocket_speak()

PURPOSE
--------
Convert model responses into spoken audio using the Pocket TTS service running
locally on port 8000. Enables audible feedback for Nova conversational sessions,
tutorials, narratives, and alerts without external cloud dependencies.

----------------------

BACKEND STRATEGY (3-TIER FAILOVER)
-----------------------------------
1. SERVE ENDPOINT: POST to /tts with form-encoded or JSON payload
2. CLI FALLBACK: pocket_tts generate --voice --text --output-path
3. MODEL IMPORT: Direct Python TTSModel.generate_audio()

USAGE EXAMPLES
---------------
# Basic call with auto-play (Windows only)
from nova.tts_tool import speak

result = speak(
    text="The moon rises over the regolith plains.",
    seat="chronicler",          # Use charles voice
    auto_play=True              # Auto-play on Windows
)

if result["ok"]:
    print(f"✓ Spoke {len(text)} chars as '{result['voice']}'")
    print(f"  Saved: {result['path']}")
else:
    print(f"✗ Error: {result.get('error')}")


# Override voice directly
result = speak("Attention team, emergency protocol initiated.", seat="sentinel", voice="javert")

# Silent generation (no auto-play)
result = speak(text, seat="brief", auto_play=False)


ERROR RESPONSES
----------------
{
  "ok": false,
  "error": "<reason>",
  "voice": "<requested_voice>",
  "note": "<fallback_error_if_any>"
}

Common errors:
- "empty or whitespace text" — No input provided
- "No WAV generated. Last attempt error." — All fallbacks failed
- Note field may contain CLI spawn failure message


INTEGRATION WITH NOVA DAEMON
-----------------------------
The TTS tool integrates with the Nova daemon jobs table (NOVA.db):

  - Job: tts:PATH    → Generate speech for specific file content
  - Job: speak:N     → Named seat request (N = voice name)

Example daemon loop usage:
```python
from nova import db, tts_tool

if event == "storytelling":
    response = tts_tool.speak(
        text=model_response,
        seat="chronicler",
        auto_play=False  # Daemon doesn't auto-play
    )
    if response["ok"]:
        db.put_fact("Tx-SPEAK", f"{db.zulu()}", json.dumps(response))
```
